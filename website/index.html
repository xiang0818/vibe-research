03 · Connect once

先连接 AI。
日常聊天，研究时再开启。

先选订阅或 API 并测试接入。左上角和设置页共享 Agent 开关，默认关闭；开启后沿用当前来源执行研究工具。

订阅接入 No API key

自动检测本机 Codex、Claude Code 或 WorkBuddy 的真实安装与登录状态，使用对应订阅额度。三种订阅都可运行 A 股六阶段研究；Claude 与 WorkBuddy 的研究阶段只开放产品受控 MCP。

API 接入 Bring your own

填写自己的 provider、模型和 key；探针成功后保存，全站共用这一份来源。

Agent 开关 Default off

默认关闭。普通对话不执行研究工具；深度研究、辩论与回测需要开启 Agent（更深入·较慢·费Token）。

本地隐私 Local first

key 持久保存在当前浏览器的本机配置，不是系统钥匙串；请求经本机后端转发，不进入仓库、后端配置与日志。共享电脑用完应主动清除。

04 · Evidence before confidence

把“会回答”升级成“可复核”。

每轮深度研究都会留下报告、证据、计算、冲突与运行清单。拿不到关键数据时，状态会明确变成 incomplete 或 failed，不用旧值或猜测填空。

  • 本地运行，用户数据不进入开源仓库
  • 资料数字保留来源、资料期与证据 id
  • 派生数字保留输入、函数与计算过程
  • 不推荐个股，不预测涨跌，不给买卖时机
  • 六阶段深度研究当前只支持 A 股
  • 港美研报支持本地归档与对话检索
