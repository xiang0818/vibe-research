- 本地订阅探针和业务进程统一必要环境变量白名单；无关云服务密钥及 Node 注入选项不再自动传入。Claude 保留其自身官方登录环境，Windows 变量名按大小写不敏感处理。测试专用变量移入测试私有文件，未在生产白名单开后门。
- Mac/POSIX 正常成功、异常和取消路径均检查所属进程组停止；无法确认即明确失败。补充真实进程测试覆盖主进程退出但子进程继续存活，以及拒绝 TERM 的子进程。Windows 正常成功后的孤儿进程问题没有被本修复覆盖，见下方门槛。
- 构建白名单改为精确根文件与指定目录，私密文件后缀大小写均拒绝；前端构建前按锁文件安装依赖。

## 发布边界与外部缺口

- 本轮只分发候选 Apple Silicon / macOS 13+，不宣称 Intel Mac 或 Windows 安装包。
- 无另一台全新客户 Mac 的验收；隔离数据区不是另一台实体机器。
- 当前脏工作树未跑新的远端 Windows CI；历史 CI 与本机参数测试不等于这次 Windows 实机通过。
- Windows 的正常成功退出路径尚无 Job Object 级后代进程回收保证。本轮仅实现并实测 POSIX 进程组，不宣称 Windows 该风险已关闭；在完成平台级实现和 Windows 验证前，不将这项作为 Windows 安全保证。
- 未逐个实跑所有 API 提供方及全部外部数据端点；模板兼容不等于账户/额度/地域条件均可用。
- 开放 PR #46 的 Shell Stop 路径没有因本轮固定安装版模式而被宣称修复；源码默认 Shell 路径的独立验证仍保留。PR #43 的资讯源限制也不因版本升级消失。
- 后续如需最新远端 CI、公开下载或发布资产，先获得对应授权；不得为了关闭清单而偷偷推送。
