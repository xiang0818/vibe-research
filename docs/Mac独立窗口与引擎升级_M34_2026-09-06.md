## 授权与交付变化

Simon 在看到 M33 启动后打开浏览器后，要求继续开发独立 App，并顺便检查、更新 Codex Harness。本轮 M34 使用 AppKit + WKWebView，直接在独立窗口承载现有本地界面；不是重新设计网页，也不恢复 Electron。

- 保留石墨深色/暖橙浅色、五个紧凑分类框/12 个入口、原始侧栏、品牌图标与 Agent 默认关闭。
- App 主工作区不再自动跳到外部浏览器。外部来源链接仍交给系统浏览器。
- 没有 JavaScript → Shell 桥接；只允许固定本机工作区导航和其 Blob 下载，拒绝任意远程页面占用工作区。
- App 使用自己的持久化 WebKit 存储；第一次需重新接入 AI，不复制外部浏览器的 key、聊天或登录态。
- 既有安装版数据根 `~/.vibe-research-desktop` 不改动、不清空。关闭窗口保留服务，重新打开恢复当前页；Cmd+Q 停止服务。独立后台研究须先在研究页取消。
- 使用系统文件选择/保存面板、原生提示/确认对话框；下载流式复制到目标卷临时文件后原子替换，不把整个大文件读入内存，保存期间阻止退出。

### v2接入探针修复

- 同一v1安装包复测：全来源请求60秒超时；实际子进程是WorkBuddy内置CLI的 `--help`，超过135秒仍存活，App退出后成为孤儿进程。已精确结束本次自建探针进程，未停止用户WorkBuddy应用。
- 根因是Node `execFile` 超时默认只发SIGTERM，而该CLI偶发忽略SIGTERM，promise不收尾，拖住 `Promise.all`。不是模型额度不足或网络搜索限制。
- 最小修复：只为CodeBuddy只读version/help探针使用SIGKILL超时信号，原15秒期限、订阅隔离、研究权限和账号存储不变。
